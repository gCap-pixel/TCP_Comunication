**TCP_Comunication:**

Un'implementazione semplice per la comunicazione di rete tramite protocollo TCP in JAVA che include componenti Server e Client per lo scambio di messaggi. Il progetto consente la creazione di un Server TCP, la connessione di un Client e la gestione della comunicazione.


**Installazione e Compilazione:**

Clonare la repository: git clone https://github.com.


**Utilizzo:**

Avviare prima il server e poi il client.
